My blog which ran on ghost for a while is back to github pages.

Built with [Hugo](https://gohugo.io/) using the [Archie](https://github.com/athul/archie) theme.

## New Post

```bash
./new-post.sh "Post Title" "tag1,tag2"
```

Tags are optional. Creates a file at `content/posts/YYYY-MM-DD-post-title.md` with frontmatter.
